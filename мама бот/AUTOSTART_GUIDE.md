## 🚀 Быстрый старт

**Выбери ОДИН из способов ниже:**

### Способ 1: Task Scheduler (РЕКОМЕНДУЕТСЯ) ✅
**Самый надежный способ**

1. Открой `setup_task_scheduler.ps1`
2. Кликни правой кнопкой мышки → "Run with PowerShell"
   - Может потребоваться подтверждение - нажми `Y` и Enter
3. **ГОТОВО!** Бот будет автоматически запускаться при каждой загрузке Windows

---

### Способ 2: Папка Startup
**Простой способ**

1. Открой `setup_autostart.ps1`
2. Кликни правой кнопкой мышки → "Run with PowerShell"
   - Может потребоваться подтверждение - нажми `Y` и Enter
3. **ГОТОВО!** Ярлык будет добавлен в папку автозапуска Windows

---

### Способ 3: Ручной запуск (для тестирования)
**Используй для проверки:**

Просто запусти файл **`start_bot_hidden.vbs`** двойным клико
- Бот запустится в фоновом режиме
- Проверь работает ли бот

## 🔍 Проверка и решение проблем

### Как проверить, запущен ли бот?

1. **Открой диспетчер задач** (Ctrl+Shift+Esc)
2. Найди `python.exe` в списке процессов
3. Если он там - бот работает! ✓

### Проверь логи в консоли

1. Запусти `run_bot.bat` прямо (двойной клик)
2. Ты увидишь логи в окне консоли
3. Проверь:
   - ✓ "Бот запущен"
   - ✓ "Сообщение будет отправляться ежедневно"

### Частые проблемы

#### ❌ "Python не найден"
**Решение:**
```
- Установи Python: https://www.python.org/
- При установке ✓ выбери "Add Python to PATH"
- Перезагрузи компьютер
```

#### ❌ "Ошибка при отправке сообщения"
**Решение:**
- Проверь что:
  - BOT_TOKEN правильный в `config.py`
  - CHAT_ID правильный в `config.py`
  - Интернет подключен
  - Бот добавлен в чат

#### ❌ "Модуль не найден"
**Решение:**
```
Откой PowerShell и выполни:
pip install -r requirements.txt
```

## 🛑 Остановка бота

### Способ 1: Диспетчер задач
1. Ctrl+Shift+Esc
2. Найди `python.exe` или `cmd.exe`
3. Правый клик → "Завершить задачу"

### Способ 2: Командная строка
```
taskkill /F /IM python.exe
```

### Способ 3: Task Scheduler (если через него запущен)
1. Открой "Планировщик задач"
2. Найди "Mama Bot Auto Start"
3. Правый клик → "Отключить"

## ℹ️ Дополнительно

### Где искать логи бота?
Когда бот запущен через `run_bot.bat`, все сообщения выводятся в консоль.
Для сохранения логов в файл, отредактируй `run_bot.bat`:

```bat
python main.py >> bot.log 2>&1
```

### Как изменить время отправки сообщения?
Отредактируй `config.py`:
```python
SEND_TIME = "10:00"  # Измени на нужное время HH:MM
```
