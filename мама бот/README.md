# Мама Бот 🤖

Телеграм-бот который отправляет сообщение каждый день в определенное время.

## Инструкция по запуску:

### 1. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Запустите бот:
```bash
python main.py
```

## Конфигурация:

Отредактируйте файл `config.py` для изменения:
- `BOT_TOKEN` - токен бота от BotFather
- `CHAT_ID` - ID пользователя/чата для отправки
- `MESSAGE` - текст сообщения
- `SEND_TIME` - время отправки (формат HH:MM)

## Текущие параметры:
- ⏰ Время отправки: 10:00
- 👤 ID получателя: 344117461
- 📝 Сообщение: "скинь 20 грн сыну(4441 1144 3355 8036)"

## Для фонового запуска на Windows:

Создайте файл `.bat`:
```batch
@echo off
python main.py
pause
```

Запустите через планировщик задач Windows для автоматического запуска при загрузке системы.
